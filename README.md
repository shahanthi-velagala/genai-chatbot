# GenAI Chatbot

A simple Generative AI chatbot built using Python, Flask, and Gemini API.

## Features
- Interactive chat interface
- Uses Gemini API for AI responses
- Flask backend

## Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript
- Gemini API

## How to Run
1. Install dependencies  
   `pip install -r requirements.txt`
2. Run the app  
   `python app.py`
